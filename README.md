# Ритм — дневник тренировок, задач и целей

Android-приложение (Kotlin + Jetpack Compose), мягкая фиолетовая тема, светлая и тёмная.

## Что внутри

**Планы**
- *Задачи* — календарь по неделям, задачи на день, время и напоминание, отметка/редактирование/удаление. Невыполненные задачи прошлых дней сами переезжают на сегодня (с пометкой «перенесено»).
- *ИИ-планер* — надиктуй или напиши планы сплошным текстом, ИИ разложит их по дням и времени, ты отмечаешь нужные и добавляешь.

**Тренировки**
- *Сегодня* — упражнения на текущий день недели, вводишь повторения и вес по подходам (галочка подставляет плановые значения). «Завершить» → ИИ пишет краткий отчёт со сравнением с прошлой тренировкой.
- *Питание* — фото каждого приёма пищи по дням (камера или галерея), подписи.
- *Программа* — какие упражнения в какой день недели: подходы × повторения × вес.
- *История* — все тренировки с отчётами ИИ.

**Цели** — категории (спорт, упражнения, финансы, другое), отметка выполнения; серым под целью — когда добавлена и когда выполнена; выполненные уходят в «Историю».

**Настройки** (шестерёнка сверху) — адрес API, ключ, модель (+ быстрые пресеты OpenRouter / OpenAI / DeepSeek / Claude), проверка подключения; утренний план на день и напоминание о тренировке.

## Как собрать через GitHub

1. Создай на github.com новый репозиторий (например `ritm`), лучше **приватный** — в нём лежит ключ подписи.
2. Распакуй архив и в папке проекта выполни:

```bash
git init
git add .
git commit -m "Ритм 1.0.0"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/ritm.git
git push -u origin main
```

3. Открой вкладку **Actions** — сборка запустится сама (~5–8 минут).
4. Готовый APK появится во вкладке **Releases** (удобно скачать прямо с телефона) и в артефактах сборки.
5. Установи APK (разреши установку из неизвестных источников).

Обновления ставятся поверх — данные сохраняются: подпись одна и та же (`app/ritm-release.jks`), а номер сборки растёт автоматически.

## Версии

- `version.properties` → `VERSION_NAME` — версия, которую видно в настройках. Меняется при каждом обновлении.
- `versionCode` = номер запуска GitHub Actions, растёт сам.

Чтобы залить обновление:

```bash
git add .
git commit -m "Ритм 1.0.1"
git push
```

## ИИ

Подходит любой OpenAI-совместимый API: укажи адрес вида `https://…/v1`, ключ и модель.
Для Claude укажи `https://api.anthropic.com` — приложение само переключится на формат Anthropic.

## Обновления в приложении

Приложение само проверяет Releases (не чаще раза в 6 часов) и предлагает обновиться.
Текст «что нового» берётся из файла `whatsnew.txt` — его обновляем вместе с версией.
Если репозиторий приватный — в настройках приложения нужен GitHub-токен (Fine-grained, Contents: Read-only на этот репо).
